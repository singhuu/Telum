# Contributing

Build the app and run lint before submitting a pull request. Include the Android TV version and describe how a remote user reaches the changed behavior.

Keep network work and bitmap decoding off the UI thread. Do not add continuous animation to an idle home screen. Keep optional network features explicit, preserve permission-denied fallbacks, and avoid logging account data or media titles.

For app support, provide exact package IDs and an official store or vendor reference. Distinguish a supported app palette from verified recommendations with a signed-in account.

Use GPL-3.0-only for original contributions. Do not submit copyrighted posters, account screenshots, tokens or keystores.

Use [ASD-STE100](https://www.asd-ste100.org/) for installation documents. Keep instructions to 20 words per sentence. Keep descriptions to 25 words per sentence. Use one instruction per sentence and one term for each concept. Preserve exact command names and screen labels as technical terms.
